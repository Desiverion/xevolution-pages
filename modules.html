The job it does. You send for eight to forty client domains. One of them is quietly rotting and you find out when the client emails. This module is how you find it first: a score per domain, the two failing inputs named, and a triage order to run when a domain looks suspect.

The artifact

A scored domain, in writing

You produce a scored spreadsheet with a 0 to 100 health number per client domain, a signed-off SPF, DKIM and DMARC checklist per sending domain, and a placement-test log with one comparable row per test.

How you know it works

It predicts the failure

Pick your worst-performing domain, score it cold, then run the module's triage. If the score did not predict which input was failing, the module failed.
